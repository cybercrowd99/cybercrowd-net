## Operating Doctrine

1. Build files as real files.
2. Keep public and admin surfaces separate.
3. Never expose privileged control to public pages.
4. Keep owner continuity above automation.
5. Treat swarm agents as controlled entities, not owners.
6. Treat bots as public unless explicitly authenticated through corporate channels.
7. Audit privileged actions.
8. Keep downloadable/buildable artifacts visible.
9. Prefer clear filenames over aliases.
10. Do not push to GitHub unless repo access is actually confirmed and working.

## Root Statement

CyberCrowd is a multiplex XR and admin-control system where the public can enter the world, but only sovereign/private channels can control the machinery.
