CYBERCROWD SANDBOX ROUTE ISOLATION MATRIX V1
Route isolation doctrine for CyberCrowd artificial operational sandboxes. This matrix defines what DEV and STAGING systems may touch, what they must never touch, and how controlled promotion may occur.
ISOLATION-001
Core Rule
Sandbox systems are not Production systems. DEV may break safely. STAGING may prove safely. PRODUCTION must remain clean. No sandbox route may silently write into live operational truth.
ISOLATION-002
Environment Isolation Matrix
Environment May Write To May Read From Must Never Write To
DEV DEV_REPLAY, DEV_HEARTBEATS, DEV_SEQUESTER, DEV_DEADLETTER static docs, mock fixtures, local schemas Production R2, Production Pages bindings, live canon
STAGING STAGING_REPLAY, STAGING_HEARTBEATS, STAGING_SEQUESTER, STAGING_DEADLETTER approved fixtures, copied test-only snapshots Production canon, Production lineage, Production governance
PRODUCTION Production R2 lattice only under authority rules Production R2 lattice DEV buckets, STAGING buckets, fake simulation paths
ISOLATION-003
Allowed DEV Routes
DEV may route: fake cursor event → DEV_REPLAY fake heartbeat → DEV_HEARTBEATS fake upload → DEV_SEQUESTER fake failure → DEV_DEADLETTER fake drag transfer → DEV_SEQUESTER fake clipboard event → DEV_SEQUESTER DEV may not route to: LEDGER_EVENTS LINEAGE GOVERNANCE ARCHIVE Production REPLAY Production NODE_HEARTBEATS
ISOLATION-004
Allowed STAGING Routes
STAGING may route: controlled replay test → STAGING_REPLAY controlled heartbeat test → STAGING_HEARTBEATS controlled intake test → STAGING_SEQUESTER controlled failure test → STAGING_DEADLETTER controlled transport simulation → STAGING_REPLAY + STAGING_HEARTBEATS STAGING may not route to Production authority lanes unless a governance-reviewed promotion is explicitly approved.
ISOLATION-005
Production Isolation Rule
PRODUCTION may never consume sandbox state as truth. Sandbox data may become Production eligible only through: 1. export as reviewed artifact 2. governance review 3. schema validation 4. replay compatibility check 5. lineage eligibility check 6. controlled release gate Sandbox object promotion is not automatic.
ISOLATION-006
One-Way Promotion Path
Allowed promotion direction: DEV → STAGING → governance review → release gate → PRODUCTION Forbidden promotion direction: PRODUCTION → DEV overwrite STAGING → Production live canon without review DEV → Production direct
ISOLATION-007
Replay Isolation
DEV_REPLAY may contain fake replay chains. STAGING_REPLAY may contain controlled replay proof. Production REPLAY may contain only Production-authorized replay records. Forbidden: sandbox replay object in Production replay path. Forbidden: Production replay overwrite by sandbox replay.
ISOLATION-008
Heartbeat Isolation
DEV_HEARTBEATS may contain fake pulses. STAGING_HEARTBEATS may contain controlled liveness tests. Production NODE_HEARTBEATS may contain live node continuity only. Forbidden: fake heartbeat pulse entering Production liveness telemetry.
ISOLATION-009
Cache Isolation
Sandbox cache tests may not populate Production SURFACE_CACHE. Production SURFACE_CACHE may only receive: - approved public media - approved render assets - approved cache objects - intentional acceleration artifacts Fake cache objects must remain: DEV or STAGING only.
ISOLATION-010
Governance Review Gate
A sandbox result may influence Production only when GOVERNANCE records: - reviewed artifact - review timestamp - reviewer authority - affected route - affected bucket - release condition - rollback condition No invisible promotion.
ISOLATION-011
Forbidden Cross-Lane Routing
Forbidden: DEV_REPLAY → Production REPLAY Forbidden: DEV_HEARTBEATS → NODE_HEARTBEATS Forbidden: DEV_SEQUESTER → Production SEQUESTER Forbidden: STAGING_DEADLETTER → Production DEADLETTER Forbidden: sandbox upload → ARCHIVE Forbidden: sandbox identity → LINEAGE Forbidden: sandbox override → GOVERNANCE Forbidden: sandbox object → SURFACE_CACHE public release
ISOLATION-012
Final Rule
Artificial worlds are allowed to fail. The living system is not. Sandbox lanes exist so CyberCrowd can learn, break, simulate, rebuild, and prove without contaminating Production truth.
