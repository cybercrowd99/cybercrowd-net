# PixelPrix — Google Play Data Safety Draft

## App name
PixelPrix / CyberCade PixelPrix

## Core purpose
PixelPrix is a local camera clean-up game. The player takes a room picture, treasure pictures, and optional short voice replays for cleanup play.

## Data collection summary
The local game flow is designed to keep pictures and voice replays on the device.

## Data types

### Photos and videos
Used by the game camera flow to take room, treasure, and before/after pictures.

Collection:
- Local device use only in the intended game flow.
- Not uploaded by this local game flow.
- Not shared by this local game flow.

Purpose:
- App functionality.

### Audio
Used for short treasure voice replays after a treasure snap.

Collection:
- Local device use only in the intended game flow.
- Not uploaded by this local game flow.
- Not shared by this local game flow.
- Not used for speech-to-text in the intended local flow.

Purpose:
- App functionality.

### Device or other IDs
Do not collect for PixelPrix local gameplay unless a later Android wrapper or SDK adds them.

### Location
Do not collect.

### Contacts
Do not collect.

### Account info
Do not collect.

### Advertising ID
Do not collect.

### Analytics
Do not use analytics in PixelPrix local game flow unless added later and disclosed.

## Sharing
PixelPrix local game flow does not share pictures, voice, or personal data with third parties.

## Security practices
Data stays local in device/browser storage during the local game flow.

## Delete data
Local game memory can be cleared on device when the clear function is available. Users can also clear app/browser storage from device settings.

## Children / Families
PixelPrix may be used by families. Camera and microphone use should be supervised by a parent or guardian. No ads, behavioral tracking, account signup, upload, or public sharing should be included in the child/family local game flow.
