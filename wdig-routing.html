CyberCrowd WDIG Routing

Where things belong inside the CyberCrowd system.

Where We Belong

WDIG Routing is CyberCrowd’s placement layer. It asks where something belongs before it is moved, surfaced, archived, controlled, broadcast, connected, or preserved.

Routing Purpose

The purpose of WDIG Routing is to prevent confusion. CyberCrowd should not throw every person, file, device, signal, record, proof object, or surface into one feed, one bucket, or one room.

WDIG Routing protects correct placement, correct custody, correct surface, correct lane, correct control path, correct archive path, and correct live signal path.

Placement

Placement decides where something should enter CyberCrowd. A file, camera, person, device, record, or signal must be placed in the correct system area before it becomes active.

Custody

Custody defines who or what is responsible for an object while it moves through CyberCrowd. Custody protects meaning, access, proof, and control.

Surface

A surface is where something appears or becomes usable. WDIG Routing helps decide whether an object belongs on a live surface, private surface, public surface, creator surface, client surface, archive surface, or control surface.

Lane

A lane keeps work separated. WDIG Routing helps CyberCrowd avoid mixing jobs, media, live signals, proof records, marketplace signals, archive objects, and control paths into the wrong place.

Control Path

A control path defines how an operator, creator, client, worker, device, or system surface may control movement. WDIG Routing does not give control to everything. It routes control only where control belongs.

Archive Path

When something becomes evidence, history, proof, or a platform lesson, WDIG Routing may move it toward the CyberCrowd Archive. The archive path preserves meaning, custody, version history, and proof.

Live Signal Path

Live signals may come from phones, cameras, devices, rooms, events, viewer inputs, creator controls, or trusted surfaces. WDIG Routing decides where those live signals belong before they are shown, mixed, queued, dropped, preserved, or archived.

Routing Boundary

WDIG Routing answers one question:

Where does this belong?

This page does not define worker capture, proof resume records, barcode inventory, estimator workflows, or local marketplace search. Those are separate CyberCrowd lanes.
