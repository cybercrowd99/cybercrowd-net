CYBERCROWD R2 ROUTING AUTHORITY MATRIX V1
First operational routing matrix for the CyberCrowd persistent R2 lattice. This document defines what routes where, under what authority, and under what containment rules.
MATRIX-001
Canonical Authority Rule
Rule: Canonical truth never routes through cache. Replay never overwrites canon. Governance annotates authority but does not silently mutate canon. Deadletter and Sequester isolate failure and suspicion away from live lanes.

MATRIX-003

Canon: LEDGER_EVENTS Replay: REPLAY Ownership: LINEAGE Authority: GOVERNANCE Containment: DEADLETTER SEQUESTER Acceleration: SURFACE_CACHE Telemetry: NODE_HEARTBEATS Public delivery: GRAPHICS TEASERS Cold retention: ARCHIVE
MATRIX-004
Forbidden Routing
Forbidden: SURFACE_CACHE → canonical writes Forbidden: REPLAY → overwrite canon Forbidden: GOVERNANCE → silent canonical mutation Forbidden: public uploads → bypass SEQUESTER Forbidden: heartbeat flood → direct canon writes Forbidden: failed routes → return to public lane
MATRIX-005
Operational Safety
Every route must define: - authority - visibility - containment - replay behavior - fallback behavior No route is allowed to exist without: - ownership definition - failure destination - authority scope
